# Web Personal

Mi página web personal / portafolio para el CV, donde muestro capturas y demos de mis proyectos.

## Estructura
- `frontend/` — React + Vite + Bootstrap
- `backend/` — Node.js + Express
- `Boveda_Obsidian/` — Documentación del proyecto

## Arrancar frontend
```bash
cd frontend
npm install
npm run dev
```

## Arrancar backend
```bash
cd backend
npm install
npm run dev
```

Ruta de prueba: `GET http://localhost:3000/api/salud`
