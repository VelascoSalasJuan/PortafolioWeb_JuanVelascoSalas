# Contexto del negocio

**Portafolio Virtual** — Sitio web personal para el CV, con sección de presentación profesional y galería de proyectos (incluyendo la tienda virtual BOBEDAS y otros proyectos).

- Mercado: Global / México. Idioma de la interfaz: español.
- Propósito: Mostrar experiencia, habilidades y proyectos desarrollados en el desarrollo web.

## Rutas de la app

| Ruta | Página |
| --- | --- |
| `/` | Home (Inicio) |
| `/about` | Sobre mí |
| `/portafolio` | Portafolio de Proyectos |
| `/contact` | Contacto |
| `*` | 404 |

Router: `BrowserRouter` / `React Router`.
